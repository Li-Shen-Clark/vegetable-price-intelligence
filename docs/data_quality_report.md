# 蔬菜批发价格数据质量报告

版本：P0 v0.1  
评估日期：2026-09-11  
历史数据范围：2014-02-02 至 2022-06-22  
范围：30 种蔬菜、269 个原始市场名称、117 个正式城市

## 1. 结论

P0 数据层可以支持历史 Price Monitor、Tier A 序列的预测回测，以及后续价格冲击传播研究。六个正式 Parquet 已通过行数、哈希、主键、映射、质量逻辑、聚合守恒和 Tier 完备性测试。

最重要的限制不是缺少记录，而是报价黏性和来源集中：55.78% 的市场记录与前一日价格相同，12.40% 已形成至少 7 天的连续零变动，88.30% 的城市日只有一个有效报告市场。这些风险已经进入质量字段、城市可靠性评分和 Tier 门槛，没有通过删行隐藏。

该数据不能用于当前采购决策或 2026 年实时预测。最新记录停在 2022-06-22，距本次评估日 1,542 天；项目目前也没有定时更新历史，因此“数据更新失败率”没有可计算的运行分母。

## 2. 七项数据平台指标

| 指标 | 计算 | 结果 | 判断 |
|---|---|---:|---|
| 按记录市场匹配率 | `mapped_existing_city / 全部来源行` | 8,652,295 / 8,682,381 = **99.6535%** | 达到 P0 预设的 99.5% 目标 |
| 有效价格率 | `observed_price > 0 且有限` | 8,651,109 / 8,682,381 = **99.6398%** | 高；31,272 行无效价仍保留 |
| 重复记录率 | 被标记为同市场×蔬菜×日重复的来源行 | 76,436 / 8,682,381 = **0.8804%** | 城市聚合前按市场日中位数去重权重 |
| 城市日度覆盖率 | 有效城市日 / `30×117×3,063` | 7,358,606 / 10,751,130 = **68.4450%** | 蔬菜和城市差异大，不能用单一全局城市名单 |
| 当前省份冲突率 | 映射 v0.2 下 `raw_province ≠ market_province` | 107,948 / 8,682,381 = **1.2433%** | 全部为兵团报送口径与正式地理省份差异，保留双字段 |
| Tier A/B/C | 3,510 个蔬菜×城市组合 | **A 919 / B 1,814 / C 777** | A 用于历史正式回测，B 用于 Monitor，C 仅保留可见性 |
| 数据更新失败率 | 失败更新次数 / 计划更新次数 | **N/A** | 当前是静态历史项目，没有计划任务和运行台账；不能报告 0% |

补充口径：映射 v0.2 有 246 个市场属于正式 117 城市，23 个市场属于范围外城市；范围外记录为 30,086 行（0.3465%），保留在市场事实表但不进入城市聚合。

## 3. 行级价格质量

| 指标 | 行数 | 占全部来源行 |
|---|---:|---:|
| 非正/无效价格 | 31,272 | 0.3602% |
| 可复核历史环比 | 8,651,109 | 99.6398% |
| 环比不一致 | 0 | 0.0000% |
| 重复来源行 | 76,436 | 0.8804% |
| 逐日零变动 | 4,843,132 | 55.7812% |
| 连续至少 7 日零变动（stale） | 1,076,207 | 12.3953% |
| 只用历史窗口得到的异常候选 | 168,143 | 1.9366% |

30 个蔬菜的零变动率范围为 48.68%–73.32%，stale 率为 6.10%–34.10%，异常候选率为 1.28%–3.50%。绿豆芽的零变动率和 stale 率最高，分别为 73.32% 和 34.10%，其正式 Tier A 城市也只有 3 个。

`stale_quote_flag` 和 `outlier_flag` 都是候选风险，不是错误标签。异常规则只读取当前行之前最多 90 条报告，至少有 30 条有效历史才判定，避免未来信息泄漏。任何标记都没有改写原始价格。

## 4. 市场映射与省份口径

映射表覆盖全部 269 个原始市场名称，市场状态为：

- `mapped_existing_city`：246 个市场，8,652,295 行；
- `unmapped_new_city`：23 个市场，30,086 行；
- `unmapped_unknown`：0 个市场，0 行。

映射率没有通过模糊匹配强行做到 100%。23 个范围外城市市场仍可用 `identified_city` 和 `identified_province` 追踪，但正式 `market_city` / `market_province` 为空。

初始冲突审计发现 193,023 行（2.2232%）：其中 85,075 行来自两条张家界市场的旧省份映射错误，已经通过映射 v0.2 正式更正；剩余 107,948 行来自新疆生产建设兵团报送口径与新疆维吾尔自治区地理口径的差异。项目保留 `raw_province` 与 `market_province` 两列，不把口径差异覆盖为“清洗后无冲突”。

## 5. 城市聚合质量

8,621,252 条“已映射且有效”的来源行先归并为 8,581,964 个等权市场日，再生成 7,358,606 个城市日。额外的 39,288 条重复来源行不会使某个市场获得更高权重。

| 城市日质量 | 行数 | 占城市日 |
|---|---:|---:|
| `good` | 6,289,840 | 85.4760% |
| `caution` | 253,668 | 3.4472% |
| `poor` | 815,098 | 11.0768% |
| 只有一个报告市场 | 6,497,513 | 88.2982% |

城市主分析价格使用市场日价格的中位数。另存的 `trimmed_mean_price` 按两端各 10% 的标准整数修剪定义计算，但数据中单个城市日最多只有 8 个市场，因此 `floor(n×10%)` 始终为 0；该字段在当前样本里实际等于普通均值。不能声称它实际剔除了极端市场。

城市分析价格范围为 0.01–1,560 CNY/kg。两端极值没有被自动删除，因为原始数据缺少等级、规格、包装和成交量，无法仅凭价格大小证明来源错误。中位数降低了极端值对城市主价格的影响，异常占比则保留在质量字段中。

## 6. 覆盖与 Tier

Tier 使用统一的 3,063 日窗口，完整保留 30×117 = 3,510 个组合，包括 118 个完全没有有效城市日的组合。

| Tier | 组合数 | 占比 | 使用边界 |
|---|---:|---:|---|
| A | 919 | 26.18% | 截至 2022-06-22 的历史正式预测与回测 |
| B | 1,814 | 51.68% | 历史 Price Monitor；不进入正式预测 |
| C | 777 | 22.14% | 原始数据和质量报告可见；不进入产品指标 |

每种蔬菜的 Tier A 城市数为 3–44，中位数 31。这个结果低于仅用“有效日期≥2,500”得到的 35–52 个参考候选，因为正式规则还要求活跃跨度覆盖、最长内部缺口、尾部缺口、stale、outlier 和 poor 日占比同时达标。

Tier A 最常见失败项为有效日期不足、活跃跨度覆盖不足和内部缺口过长。`coverage_score` 便于排序和诊断，但 Tier 使用逐项绝对门槛；不能仅凭总分反推资格。详细产品计数见 `docs/coverage_tier_summary.md`。

## 7. 可处理与不可处理的问题

### 已处理或显式标记

- 原始字段类型、日期和价格解析；
- 市场名称到正式城市的版本化映射；
- 范围外城市与未知映射的区分；
- 原始省份与正式地理省份双口径；
- 非正价格、重复来源行、连续零变动、stale 和历史异常候选；
- 同城市多市场的等权稳健聚合；
- 缺失日期、最长缺口、近期性与产品×城市 Tier；
- 从来源 CSV 到 Gold 的哈希、行数、主键和聚合守恒测试。

### 当前数据无法解决

- 报价对应的蔬菜等级、规格、包装和质量；
- 各市场内部报价是否成交量加权，以及真实成交量；
- 来源“前一日价格”在停报时的精确定义；
- 缺报、报价结转与真实低波动之间的完全区分；
- 公路里程、运输时间、运费、损耗率和供应能力；
- 2022-06-22 之后的市场价格及任何 2026 年实时状态；
- 没有计划任务运行台账时的数据更新失败率。

这些限制意味着后续采购模块只能做参数化情景比较，不能把“低报价城市”直接称为可执行供应商或已验证的节省机会。

## 8. 下游使用建议

- **Price Monitor：可行。** Tier A/B 可以展示历史趋势、排名、季节区间和质量标记；界面必须显示数据截止日。
- **概率预测：有条件可行。** 只对 Tier A 和已锁定的 10 种核心蔬菜做 rolling-origin 回测，并与 last-value 基准比较。
- **风险预警：需先冻结事件定义。** 数据质量标记不能替代涨价事件标签。
- **采购情景：只能模拟。** 必须外接运费、损耗、容量和当前报价后才能用于真实业务。
- **价格冲击传播：可作为高级分析。** 使用 Tier A、3 日或周频、公共因子剔除、FDR 和样本外增益验证，不能从同期相关直接推断传导。
