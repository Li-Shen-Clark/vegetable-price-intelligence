## 1. 结论

P2 MVP 使用旧项目已经采用、且位于 `SDvegetableList.csv` 前 10 位的蔬菜：大白菜、圆白菜、黄瓜、西红柿、土豆、青椒、白萝卜、芹菜、茄子、洋葱。

P0 数据管道仍处理全部 30 种蔬菜。本次锁定只限定 P2 首轮预测、回测和模型比较的核心产品，不删除其他产品，也不保证所有入选产品最终都通过预测验收。

## 3. 为什么保留原项目的 10 个

1. 数据门槛全部通过，没有产品因日期或有效价格不足需要被替换。
2. 保留旧项目范围可以直接复用并比较既有 market integration 研究结果，减少“换样本后指标改善”的解释风险。
3. 组合包含叶菜、茄果/瓜类、根菜、块茎和鳞茎，可观察不同易腐性与耐储性的价格行为。
4. P2 的目标是先建立可信的 rolling backtest 和概率预测，不是一次覆盖全部 30 种产品。

## 4. 已知局限

- 按 `dim_vegetable` 的历史价格档位，入选组合为 `low = 5`、`medium = 4`、`high = 1`，高价品类代表性偏低。
- 组合中易腐性为 `high = 7`、`medium = 1`、`low = 2`，更偏向鲜食高频品类。
- 本次市场数是原始市场名称数，不是经过正式映射后的城市数。P0 的 Tier 分层完成后，P2 仍须按“蔬菜×城市”重新应用数据门槛。
- 若部分产品不能稳定优于简单基准，应缩小正式预测范围，而不是为保持 10 个数量而放宽验收标准。

## 5. 后续扩展顺序

如果 P2 首轮稳定，优先从候选池补充高价或耐储品类，例如生姜、蒜头和尖椒；具体扩展必须依据正式 Tier 覆盖和样本外回测另写计划。
