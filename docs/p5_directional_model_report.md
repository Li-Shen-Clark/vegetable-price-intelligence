## 解释边界

FDR 只控制当前地理候选集合中的多重检验；它不证明贸易联系或因果传播。进入下一阶段的边还必须通过训练分窗、时间块 bootstrap 和 final-test 样本外增益。

Gate：`conditional_pass_to_stability`。
