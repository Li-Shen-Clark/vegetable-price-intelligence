## 3. P5 必须先冻结的分析契约

P5 的第一项任务是在本地阶段计划中建立 Economics & Pricing Hypothesis Card，并至少冻结以下内容；最终结论再提炼到公开路线图和模型卡：

1. **决策对象：** 当一个城市出现价格冲击时，哪些城市需要提前扩大成本与报价复核范围，以及提前多少天。
2. **分析单位：** 城市×产品×3 日或周频；日频原始价格不得直接用于传播边估计。
3. **候选城市：** 各产品 Tier A 城市；候选边必须根据距离、同省/邻省或训练期关系事前限制。
4. **共同冲击控制：** 在训练窗口估计全国/大区中位数、PCA 或动态因子，并只在去除公共成分后的变化上检验方向关系。
5. **预测基准：** 目标城市自身滞后项与公共因子是最低基线；加入来源城市信息必须在连续时间样本外产生增益。
6. **统计校正：** 预先冻结滞后范围、FDR 水平、Bootstrap/置换规则、边稳定性标准和最终测试只使用一次的纪律。
7. **降级路线：** 若方向边不稳定，只发布共同因子、冲击共振和区域暴露结果，删除传播方向与网络因果措辞。

## 4. Economics & Pricing Gate

| Gate | P5 开工口径 |
|---|---|
| G1 决策 | 输出用于提前触发成本、供应和报价人工复核，不执行调价 |
| G2 机制 | 把空间套利/信息扩散与共同冲击放在同一竞争解释框架中 |
| G3 约束 | 频率、城市选择集、候选边、滞后和可靠性必须可复算 |
| G4 基准/识别 | 默认只称方向性预测关系；无额外识别设计不得称因果传播 |
| G5 稳健性 | FDR、重采样、时间窗口稳定性和样本外增益缺一不可 |
| G6 Pricing 接口 | 传播信号扩大复核范围或提前复核时间，是 Pricing Engine 的风险输入 |
| G7 边界 | 页面同时展示历史截止日、共同冲击解释和网络不稳定性 |

P5 当前 Gate 为 `conditional_pass_to_plan`：经济问题和最低证据已明确，只有在实际结果通过统计与样本外门槛后，才可升级为传播模块 release。
