# P6 求职作品集可交付性审计

## 结论

项目已经具备足够强的 Pricing / Economics / Data Science 技术证据，但当前入口更像完整项目文档，而不是招聘经理能在 3–5 分钟内读懂的 Case Study。P6 的最高价值不是继续增加模型，而是建立一条无数据也能被理解和验证的招聘路径，并把代码质量与 CI 收口。

初始状态：`conditional_pass_to_portfolio_build`。

## 已具备的优势

| 维度 | 现有证据 | 求职价值 |
|---|---|---|
| 数据工程 | 868 万市场报价、735 万城市日事实、版本化映射与质量 Tier | 能处理非平衡面板、脏连接键和可追溯数据产品 |
| 预测治理 | P2 与强基线比较，按产品×跨度 partial release | 不把模型平均改善包装成全面胜出 |
| 决策建模 | P3 固定 FPR，P4 风险调整到岸成本与敏感性 | 能把预测转成复核、询价和成本决策 |
| 经济学 | 价格离散、季节性、交易成本、不确定性、共同冲击 | 模型选择由经济问题和竞争解释约束 |
| 研究纪律 | P5 事前候选、FDR、bootstrap 与一次性 final test | 有能力给方向网络作出可信 no-go |
| 产品表达 | 五个本地工作台、基线回退、历史/非因果边界 | 技术结果能转成可解释的用户界面 |
| 发布安全 | Git 历史无数据、无日志，严格 verifier 已通过 | 可公开代码而不暴露本地数据资产 |

## 关键缺口

| 优先级 | 缺口 | 当前证据 | 风险 | P6 动作 |
|---|---|---|---|---|
| P0 | 缺少一页式项目 Case Study | README 信息完整但较长 | 招聘方看不到清晰的决策主线 | 新建项目级 Case Study 与 evidence matrix |
| P0 | 无数据 clone 没有可直接看的页面 | 五个工作台都依赖本地 JSON | GitHub 访客只能看代码，不能快速理解产品 | 新增完全静态 `/case-study` |
| P0 | 缺少针对求职的简历与演示材料 | 只有分阶段 interview guide | 面试叙事容易碎片化 | 建立岗位版 bullets 与 3–5 分钟脚本 |
| P0 | 缺少 Pricing Engine 接口定义 | 文档只描述“互补” | 业务落点仍可能显得抽象 | 定义只读证据/人工复核契约 |
| P1 | 没有 CI | `.github/workflows` 不存在 | GitHub 无自动质量信号 | 新建完全无数据的 workflow |

## 无数据模式审计

- Git HEAD 中只有 `data/README.md`，没有原始/派生 CSV、Parquet、artifacts、浏览器 JSON 或执行日志。
- 严格作品集契约、Pricing 叙事与 P5 页面边界共 14 项 code-only 测试通过。
- 现有五个工作台在没有本地 JSON 时会进入明确错误状态，但不能作为招聘主入口。
- 生产构建不需要真实数据，因此静态 `/case-study` 可以成为无数据 clone 的默认演示路径。

## 质量基线

- P0–P5 完整本地测试：152/152 通过。
- P5 页面定向 lint：通过。
- 全站构建：通过，识别五条产品路由。
- 全站 lint：失败，共 25 个存量错误；集中于未必使用的生成式 UI primitives、两个既有页面的 effect/label，以及 chart 通用组件类型。
- Git/隐私 verifier：通过。

## P6 做与不做

### 必做

- 数据无关的 Case Study 与招聘路径；
- P0–P5 证据矩阵和 Pricing 接口；
- 岗位化简历、面试和演示材料；
- 全站 lint、无数据 CI、构建与安全审计；
- P5 no-go、P2 partial release、P3 误报与 P4 参数假设全部保留。

### 不做

- 不训练新模型、不重新打开 final test；
- 不上传真实或派生数据，不用真实图表截图绕过该边界；
- 不声称生产部署、利润提升、自动调价或因果传播；
- 不为获得漂亮首页而重写五个已验收工作台；
- 不在用户未授权时部署或发布网站。

## Economics & Pricing Gate

G1、G3、G4、G5、G7 已有充分底层证据；G2 的项目级机制叙事和 G6 的 Pricing 集成接口仍需统一。因此 P6-T0 为 `conditional_pass`，放行 T1，但在 Case Study 与接口契约完成前不进入最终作品集验收。
